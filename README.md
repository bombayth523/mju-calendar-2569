โปรเจกต์นี้จัดทำขึ้นเพื่อช่วยให้นักศึกษาและว่าที่ลูกแม่โจ้ทุกคนสามารถเข้าถึงข้อมูล **ปฏิทินการศึกษาปี 2569** ได้ง่ายขึ้น สวยงามขึ้น และชัดเจนขึ้น โดยรวบรวมข้อมูลจากประกาศมหาวิทยาลัยและแหล่งข้อมูลต่างๆ มาสรุปไว้ในที่เดียว พร้อมอัปเดตข้อมูลล่าสุดเพื่อให้ทันกับเหตุการณ์สำคัญ

---

## ✨ คุณสมบัติเด่น (Features)

- **🆕 New: Preparation Roadmap**: แท็บพิเศษ "เตรียมตัวก่อนเปิดภาค" สำหรับน้องใหม่ปี 1 ที่ติด TCAS แล้ว ให้รู้ว่าต้องทำอะไรต่อ (หอพัก, รหัสนักศึกษา, กิจกรรมอัตลักษณ์)
- **📅 Smart Sorting**: เลือกดูได้ 2 มุมมอง ทั้งแบบ **"แยกตามหมวดหมู่"** (สวยงามเป็นระเบียบ) และแบบ **"เรียงตามวันที่"** (เรียงลำดับเวลาชัดเจน)
- **🚀 TCAS Full Tracking**: ข้อมูลการรับสมัครนักศึกษาใหม่ครบทั้ง 4 รอบ (1.1, 1.2, 2, 3) พร้อมวันยืนยันสิทธิ์และประกาศผล
- **📱 Fully Responsive**: ออกแบบมาให้ใช้งานได้ดีเยี่ยมทั้งบนคอมพิวเตอร์และมือถือ
- **⚡ Fast & Lightweight**: แยกโครงสร้างไฟล์ HTML, CSS, และ JS เพื่อความเร็วในการโหลดและการจัดการที่ง่าย

---

## 🛠 ข้อมูลทางเทคนิค (Tech Stack)

- **Frontend**: Vanilla HTML5, Modern CSS3
- **Logic**: JavaScript (ES6+) for Dynamic Rendering
- **Fonts**: [Sarabun](https://fonts.google.com/specimen/Sarabun) (Google Fonts)
